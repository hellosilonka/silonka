# Silonka

React/Vite storefront and admin dashboard with an Express/MongoDB API, PayHere hosted checkout, DHL shipping, Cloudinary uploads and email enquiries.

Start with [HANDOVER.md](HANDOVER.md) for configuration, local commands, PayHere setup and launch acceptance. See [AUDIT.md](AUDIT.md) for the issues addressed and verification results.

Runtime: Node.js 24.x. Configuration templates: `backend/.env.example` and `app/.env.example`. Never commit filled-in environment files or put merchant secrets in frontend environment variables.
